# Борлуулалт (borluulalt)

[![CI](https://github.com/XalMorak/borluulalt/actions/workflows/node.js.yml/badge.svg)](https://github.com/XalMorak/borluulalt/actions/workflows/node.js.yml)

Бар/рестораны борлуулалт, нөөц, илгээлт, тайлангийн веб апп.

**Live:** [borluulalt-xalmorak.vercel.app](https://borluulalt-xalmorak.vercel.app)

## Юу хийдэг вэ

- Ажилтан: өдөр, ээлж, байршил, тек сонгоод пиво эсвэл вино борлуулалт оруулна
- Ахлах: тойм, илгээлт, тайлан, нөөц, хэрэглэгч, түүх. Тойм/Илгээлт/Тайлан дээр **зөвхөн өнөөдрийн** илгээлт + ажилтан бүрийн өнөөдрийн илүү/дутуу
- Нягтлан: табууд **Илгээлт | Хэрэглэгч | Ростер**. Бүх илгээлт (Firebase `submissions` + `inbox`), шүүлт (ростер, огноо, ажилтан, байршил, тек, төрөл), ажилтан тус бүрийн илүү/дутуу, дэлгэрэнгүй (зөвхөн харах), Excel, 14 хоногийн ростер, төлөлт. **Хэрэглэгч нэмэх / засах / устгах** (өөрийгөө болон сүүлийн Ахлахыг устгах боломжгүй)
- Пиво ба вино тусдаа. Тойм / илгээлт / тайлан дээр Пиво | Вино | Нэгдсэн
- Нөөц байршлаар: Оюут бар, Манлай бар, VIP, POWER. Ахлахын **Нөөц** таб пиво + вино нэг хүснэгтэд (Бүгд | Пиво | Вино шүүлт, хайлт, нэг "Бүгдийг хадгалах"). Тусдаа "Вино" таб байхгүй болсон
- Түр хадгалалт (утас, Safari)
- Үүлэн синк автомат

## Stack

JavaScript · Firebase Realtime Database · Vercel

| `compat_fix.js` | XSS-safe alert, илгээлтийн түлхүүр (байршил орно) |

| `sync_stable.js` | Тогтвортой `cloudPush` (зөвхөн ахлах, `update`, inbox/rosters/payments-ыг хөндөхгүй), устгалын tombstone (`deleted`), Тойм render-ийг тогтворжуулах |
| `supervisor_day.js` | Ахлахын өнөөдрийн илүү/дутуу самбар, огноо түгжээ |

## Өгөгдөл

Firebase зангилаа `borluulalt`. Илгээлт: ажилтан + огноо + ээлж + **байршил**.

- `inbox/{id}` — ажилтны илгээлт (шууд)
- `submissions` — ахлахын нэгтгэсэн жагсаалт
- `rosters/{r_YYYYMMDD}` — нягтлангийн 14 хоногийн ростер
- `payments/{key}` — нягтлангийн төлөлтийн тэмдэглэл
- `deleted/{t_key}` — ахлахын устгасан илгээлтийн тэмдэг (дахин гарч ирэхгүй; тухайн ээлжийг дараа нь дахин илгээвэл харагдана)

Эрх: `employee` (Ажилтан), `supervisor` (Ахлах), `accountant` (Нягтлан). Ахлахын Хэрэглэгч таб эсвэл Нягтлангийн Хэрэглэгч таб дээр эрх сонгоно. Ахлах / Нягтлан эрхэд PIN заавал (Нягтлангийн хуудаснаас нэмэх/засах үед).

- `users/{id}` — хэрэглэгч (нэр, эрх, PIN)
- `products` — пиво/бар бараа (`stockByLoc`, `stock` = нийлбэр)
- `wines` — вино/бусад бараа, id ≥ 100 (`stockByLoc`, `stock`)
