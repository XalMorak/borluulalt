# Ажилтны борлуулалтын хуудас

Зөвхөн ID-аар нэвтэрдэг борлуулалтын бүртгэлийн систем.

## Нэвтрэх

| ID | Үүрэг |
|----|------|
| emp001 | Ажилтан — Бат-Эрдэнэ |
| emp002 | Ажилтан — Сарантуяа |
| emp003 | Ажилтан — Мөнхбаатар |
| sup001 | Ахлах |

## Онцлог

- Ажилтан: борлуулалт бөглөх, автомат тооцоо (өмнөх − дараах = борлуулсан)
- Ахлах: нийт тоо, бараа бүрийн нийлбэр, дэлгэрэнгүй
- Экспорт / Импорт JSON — төхөөрөмж хооронд өгөгдөл шилжүүлэх
